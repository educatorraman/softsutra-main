## 3. Credentials & .env File Rules (CRITICAL)
- **Where Credentials Live:** Each project stores its own API keys (Telegram BotFather token, Telegram Chat ID, Firebase RTDB secrets, Google OAuth, Cloudflare R2, Upstash Redis, Turnstile, AdSense) in local .env / .env.local files (never committed to git).
- **Never Hardcode Secrets:** Never hardcode any API key, bot token, database secret, or chat ID inside source files (src/, api/, HTML, JS/TS). Always read them via process.env.<KEY> on backend/serverless routes and import.meta.env.VITE_<KEY> (or NEXT_PUBLIC_<KEY>) on frontend.
- **Protect Secret Values (envsitter-guard):** Do NOT print, echo, log, or paste raw secret values from .env* files in terminal output or chat responses. Check only key names or boolean presence.
- **Preserve Existing .env Entries & Backups:** When updating a .env / .env.local file, modify only the targeted key(s) and keep all other keys, shell helper lines, and .env*.bak* backup files intact.
- **Sync Local .env with Vercel:** Whenever adding or updating any environment variable in local .env / .env.local, also update the matching Vercel project environment variables before deploying.

## 4. Code Architecture & Verified Engines
- **Strict Layer Isolation:** Put pure math, validation, timers, and data logic in src/engine/ (zero DOM/UI imports) and UI components in src/components/ or src/ui/.
- **No Unnecessary Packages:** Inspect package.json first and reuse installed verified engines:
  - decimal.js (ROUND_HALF_UP) for money, GST, EMI, percentages, and commissions.
  - mathjs for scientific/unit expressions (never eval()).
  - date-fns for date/duration math.
  - howler for mobile audio/mantra playback (jap_counter/Music).
  - dexie / dexie-react-hooks for offline IndexedDB storage.

## 5. Unified Auth & Telegram Infrastructure
- **Single Bot:** @AppTrayBot (AppTray Labs).
